# Papers

LaTeX or Markdown source for the technical reports about this project. Each folder holds the
published `source.zip` of the version listed, unpacked and unchanged, so the build and the
reproduction steps in its own README work from here. The report page carries the built PDF,
citation files and every earlier version.

Paper text is licensed CC BY 4.0. Code inside a paper folder states its own license in that
folder; the rest of this repository keeps its existing license.
